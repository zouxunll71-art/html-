# HTML Native Studio

连接本人 Codex 账号的 macOS HTML / UIKit 双预览工作台。支持项目接入、对话同步、图片标注、模型与速度选择、原生布局编辑和 iOS 工程导出。

## 下载与安装

1. 从本仓库的 **Code → Download ZIP** 下载，解压到任意文件夹。
2. 安装完整 **Xcode 26 或更新版本**，打开一次完成初始化，在 Xcode 设置中安装 iOS 26 或更新的 Simulator 运行时。
3. 安装 **Node.js 22 或更新版本**，安装 Codex 桌面应用并登录你自己的账号。
4. 在解压目录运行 `python3 scripts/install.py --check` 检查环境，再运行 `python3 scripts/install.py`。也可双击 `Install.command`。
5. 安装完成后，双击桌面的 **HTML Native Studio** 图标启动。安装器会自动创建指向 `~/Applications/HTML Native Studio.app` 的快捷方式，使用应用自身图标。首次编译需要几分钟，依电脑性能而定。

桌面只放快捷方式，源码与运行文件保存在用户资源库中；删除桌面快捷方式不会删除应用或项目。若桌面已有其他同名文件，安装器会保留它并为新快捷方式加编号。桌面访问受限时，可直接从 `~/Applications/HTML Native Studio.app` 启动。

目前仅支持 macOS；没有提供 Windows/Linux 安装包。此版本在本机编译并临时签名，尚未使用 Apple Developer ID 公证，不承诺下载后免依赖双击即用。

## 路径与个人数据

安装器会根据当前用户和本机环境自动生成配置，不使用开发者电脑的用户名、源码路径或模拟器编号：

- 引擎、模板与客户端源码：`~/Library/Application Support/HTMLNativeStudio/`
- 对话关联与图片附件：`~/Library/Application Support/HTMLNativeStudio-CodexClient/`
- Codex：使用当前用户自己的安装、登录、项目、技能与记忆。不会分享开发者的账号、额度、对话或业务项目。
- 接入空文件夹 / iOS 工程时，在所选项目内创建 `HTMLNativeStudio/HTML/`，包含模板、AGENTS.md、编写规范与校验工具；同级 `HTMLNativeStudio/iOS/` 存放导出的原生工程。

每台电脑的工作目录各自解析。“同步”是与这台电脑上的 Codex 同步，不是跨电脑复制别人的账号和项目。历史项目的源文件若不在本机，仍需先取得源码并添加正确路径。

可选环境变量：`CODEX_BINARY` 指定 Codex 可执行文件，`DEVELOPER_DIR` 指定 Xcode Developer 目录，`STUDIO_ROOT` 指定已配置的引擎目录，`STUDIO_APP_DEST` 指定构建的应用输出路径。

唯一日常启动入口是 `/Applications/HTML Native Studio.app`（桌面同名图标指向它）。已安装新版时，旧 `engine/scripts/launch.py` 的普通启动会转到新版；`--headless` 只供新版启动后台引擎。外部窗口菜单的工作台入口也打开新版。不要另开旧版编辑器。

清理旧版本时，可移除旧的“HTML 原生工作台.app”和“HTML Codex 工作台.app”启动器；不要按文件夹名称直接删除 `Library/Application Support/HTMLNativeStudio-Share-1.0.2`。新版仍可能使用其中的引擎、Workspace、Projects、配置和模拟器工具，先核对实际依赖。

升级安装前请退出工作台及其后台服务。安装器保留本机配置、项目和账号数据；不会自动结束正在执行的任务。服务只监听本机，使用 18775 和 18777 端口；占用时需要先关闭冲突版本。

## 给 Codex 使用的后台同步窗口

工作台启动后提供本机镜像地址 `http://127.0.0.1:18777/mirror`。这是供 Codex 检查界面和辅助操作的入口，使用者继续使用桌面工作台，无需打开或管理额外窗口。

- Codex 使用浏览器工具在**后台隐藏标签页**打开镜像，不弹出窗口、不切换用户正在使用的应用。应用本身不会自动创建 Codex 的浏览器标签页；由具备浏览器工具的 Codex 按需连接。
- 镜像显示桌面工作台的当前画面。桌面端的变化会更新到镜像；镜像中的点击、滚动和文字写入会作用于同一个桌面工作台，并非独立副本。操作前先检查当前项目和未发送草稿。
- 输入文字时，先点击镜像中的目标输入框，再使用镜像页的文字写入入口。不要把查看权限理解为可以发送消息、修改项目或执行其他任务；操作仍须符合使用者当前请求。
- 复杂拖拽、系统文件选择器以及未支持的原生控件，仍使用桌面操作工具。不得声称镜像已支持所有桌面操作。
- 当前约每 1.2 秒请求刷新，不是高帧率视频。只有连接镜像时才采集画面，断开后约 5 秒停止采集；无人连接时不持续截图。镜像功能本身不调用 AI 模型。
- 镜像只在本机提供，使用当前电脑的工作台与账号。不要将端口对外公开。桌面工作台关闭时可能显示最后画面，以同步状态为准；重启后页面会尝试重连，若提示认证失效则重新打开镜像地址。

维护本工作台的 Codex 先阅读根目录 [AGENTS.md](AGENTS.md)。新接入项目里的 `HTMLNativeStudio/HTML/AGENTS.md` 也包含这一入口说明；已有项目不会被自动覆写规范。

## 默认修复流程

修改完成后，Codex 默认可以自行执行必要的本地校验、构建和加载更新，并在隐藏浏览器镜像中查看、操作本次修复的页面，发现问题后继续修复与复测，无需使用者逐次提醒或确认。若使用者明确要求不构建或自己测试，则遵循该要求。重启前保留草稿、附件和运行任务；交付说明实际验证结果，不能只以构建成功宣称修复完成。完整规范见根目录及新项目模板的 AGENTS.md。

## 开发与校验

```sh
npm ci --ignore-scripts
npm run test:unit
python3 scripts/check_distribution.py
```

`npm test` 还包括已运行的本机服务接口测试。`npm run build:mac` 构建客户端，需要先完成安装、具有已生成令牌的本机引擎。

`engine/` 包含原工作台源代码、模板和规范，`native/` 为客户端宿主与构建脚本，`web/` 为对话界面。Codex App Server 为实验接口，官方更新可能需要适配。本项目不是 OpenAI 官方客户端。

GitHub 私有仓库只有受邀用户可以下载；公开仓库可供所有人下载。第三方组件说明见 [THIRD_PARTY_NOTICES.md](engine/THIRD_PARTY_NOTICES.md)。本项目暂未授予额外的开源许可证，转载或再分发请联系仓库所有者。

## 新项目目录（v1.0.15 起）

```text
项目目录/
└── HTMLNativeStudio/
    ├── HTML/          # app.json、页面、资源、项目规范
    └── iOS/           # 导出的 Xcode 工程，每次导出独立目录
```

只应用于以后新建、接入和导出。现有项目的源码与关联路径不迁移。旧格式项目导出时，在其 HTMLNativeStudio 目录内生成 HTML 源码副本和 iOS 工程；原源码仍是编辑入口，HTML 副本首次创建后不自动覆盖。每次独立导出包使用带编号的新目录，保留历史包；如果接入外层 Xcode 空工程，再次导出会更新外层上次生成的代码和资源，详见下文。新建工程的原生目录在首次导出前为空。

### 工作台任务权限

工作台创建、恢复对话及发送新一轮任务时默认使用完整文件与网络访问（`danger-full-access`），命令审批设为 `never`。此设置作用于工作台发起的任务，不修改官方 Codex 的全局配置。已由官方 Codex 占用并接收排队消息的任务沿用其当前权限；切换权限需在拥有该任务的客户端完成。

完整访问不等于自动代答插件表单、账号登录或 macOS 权限请求。插件提问应展示插件名称、实际问题及所需字段，不应显示原始协议名称或空白 `{}` 授权框。

### 画布多选快捷键

在 iOS 画布的“选取与编辑”状态，按住 Command（⌘）点击资源可加入多选；再次点击已选资源会取消该项。松开 Command 后恢复当前工具的正常行为，不会自动取消已选资源。左侧“多选”按钮仍可用于持续多选。此快捷键仅作用于画布资源点击，不拦截输入框的复制、粘贴等快捷键。

### 手机内容裁切规则
原生渲染、HTML 预览和选框共同使用实际内容范围判断裁切。没有滚动范围且没有显式裁切的滚动容器只承担布局，不在安全区边缘截断向外移动的资源；超出容器的滚动内容、显式裁切容器和图片继续保留裁切。安全区布局和手机屏幕外壳边界不变，规则适用于所有项目。

### 移动手势
“移动”工具在已有选区时固定移动该选区，包含多选成员之间的空隙；拖动过程中不重新命中底层资源，也不触发缩放或旋转手柄。鼠标拖动与滚轮/触控板滚动使用独立识别器，拖动结束不触发点击取消选择。单击空白仍可取消选择。此规则适用于所有项目。

### 导出到自己创建的 Xcode 空工程
推荐结构：外层放你的 `.xcodeproj` 和应用源码目录；同层的 `HTMLNativeStudio/HTML` 是预览源码，`HTMLNativeStudio/iOS` 保存导出包、迁移清单与备份。日常工作目录限制在 HTMLNativeStudio 内，开发、预览与同步不会迁移到外层。

点击导出时，系统先在 HTMLNativeStudio/iOS 生成完整成品，然后接入外层工程：生成代码、图片、字体与本地化文件放进应用源码目录的 `StudioGenerated`；空白 `ViewController.swift` 接入成品运行页面。外层 Xcode 工程文件、签名、Bundle ID、构建设置、Info.plist、AppDelegate、SceneDelegate、Storyboard、AppIcon 保持不变。成品使用随包资源，不包含工作台编辑工具，也不连接工作台同步服务。

导出后工作区仍可编辑，外层成品不会自动变化。再次点击导出才替换上次生成的代码和资源，并移除过期生成文件；备份保存在 HTMLNativeStudio/iOS/HostBackups。如果你手动改过外层生成代码，导出会停止，避免静默覆盖。不要直接删除迁移清单。

当前自动接入支持截图所示的 UIKit Storyboard 空工程：唯一 App target、一个 Xcode 文件夹同步源码目录，以及默认的 ViewController 启动页。多个 target、旧式手动文件引用、SwiftUI 或已自定义的启动页会明确报错，外层不作修改。没有外层 Xcode 工程的项目仍导出独立工程。权限和其他工程配置由你在 Xcode 中管理，系统不覆盖它们。

### 启动页编辑与资源工具

左侧工具栏的 ＋ / − 调整选中资源大小，资源和选框同步变化，不是手机画布缩放。“编辑启动页”位于左侧 iOS 手机下方，与“添加文字、添加色块、内部图层”同排；进入启动页编辑预览时不执行 onEnter，清除当前预览会话的延时动作；切回运行预览后重新执行启动流程。此状态不修改项目跳转声明、外层 Xcode 的 LaunchScreen 或工程配置。

“编辑启动页”为同一按钮切换：进入后显示“关闭启动页编辑”，再次点击解除暂停并重新执行启动页正常进入流程；保留已做的布局修改。按钮状态随当前项目的预览会话更新。

多选时每个资源保留独立选框，移动时分别跟随资源位置；整体边界只用于定位多选缩放手柄，不再绘制合并大框。

### 运行模式输入

运行预览时点击左侧模拟器输入框后，工作台将键盘输入、回车和退格转发到专用模拟器；退出运行模式即释放键盘焦点。文字沿用模拟器专用剪贴板通道，首次粘贴可能需要 iOS 允许；不会覆盖 Mac 剪贴板。退格不再被编辑器删除图层快捷键拦截。

模拟器输入优化：数字、小数点和负号通过持续 HID 连接发送，不再逐字启动剪贴板命令；连续文字合并后使用专用粘贴通道。点击手机非输入区域时释放工作台键盘焦点，iOS 点击非文本控件区域也会结束输入。


### HTML 与 iOS 的选区关联

编辑模式下，在 HTML 手机或 HTML 资源列表选择图层，会按相同图层 ID 选中当前 iOS 页面中的对应图层，组合内也仅选中对应成员。只关联选区，不复制资源、不修改布局，也不转发移动、缩放或删除操作；两端编辑仍各自独立。没有对应图层或其被隐藏、锁定时清空 iOS 选区，不按相同图片或文案猜测匹配，不自动切换页面。

### iOS 默认转场

iOS 页面切换（前进、返回、Tab 与声明式弹窗显隐）默认使用 0.18 秒交叉淡入淡出，不增加跳转等待。首次显示及同页输入、滚动、布局同步不触发页面淡入淡出；系统减少动态效果开启时直接切换。独立导出沿用该默认值，可在导出的 `<前缀>App.swift` 修改 `pageTransitionDuration`（0 为关闭），或在 `<前缀>NativeBehavior.swift` 修改转场方式；再次导出遵守外层手改保护规则。

### 选框坐标

选框定位使用图层自身及全部父容器的缩放、旋转变换；点击命中、框选和祖先裁切采用同一坐标映射。拖动将屏幕位移逆变换到所属容器的坐标，父容器移动时子层随之移动。此逻辑不改写项目资源位置。


### 动画清理与验证边界

页面切换和弹窗/加载动画必须在结束、被新动画替换及中途切页时清理临时快照，恢复真实图层的最终透明度。项目声明的弹窗背景遮罩继续保留；不能为消除残影而删除正常遮罩或改动业务页面颜色。

目前已完成动画清理代码和构建校验，弹窗、加载中切页、快速连续切换的实际残影验收仍未完成。父容器变换已有坐标校验和构建证据，不能据此宣称所有资源及复杂嵌套交互均已实测通过。验收步骤见 [验收清单](engine/Protocol/Authoring/验收清单.md)，每次交付重新记录当前版本证据。

两端差异可从同步状态入口查看。默认导出直接保持当前 iOS 效果；列表中的手动处理仅用于主动改变保留策略，不是导出的前置要求。

### 导出以当前 iOS 效果为准（2026-09-22 更新）

两端同属性修改不再阻止导出，导出快照直接保留当前 iOS 覆盖。HTML 已不存在、iOS 当前未渲染的旧图层不会被恢复；条件/重复图层的覆盖仍保留，避免误删仅暂时不可见的内容。完整页面表和业务动作仍导出，不使用当前页面截图替代工程。

保存时过滤源字段缺失且等于编辑器默认值的序列化噪声；实际位置、字号、图片等修改继续保留。历史差异列表可查看，但不要求逐项处理才能导出。每个导出包包含 IOSExportResolution.json，记录采用的策略和差异；不为导出清空工作区的覆盖或历史记录。

源码未同步、资源缺失、动作/本地化错误和外层工程手改保护仍会阻止导出并报告原因。此策略不授权自动改写外层工程，仍只有明确导出才执行迁移。

### 已有关联工程的重复导出

旧源码目录与外层 Xcode 工程不在同一路径时，可在源码的 HTMLNativeStudio/iOS/export-target.json 记录已确认的工程绝对路径（project 字段）。后续明确导出先验证该目标，再生成新包并迁移到关联工程；目标丢失时报告错误，不静默导出到另一位置。日常编辑不会更新外层工程，Xcode 工程配置保持不变。

重复导出只忽略 Xcode 对 .xcstrings 的 JSON 排版及 extractionState 提取标记变化；翻译内容、其他生成代码的手动修改仍阻止覆盖。验证导出时对照外层 StudioGenerated 的页面模型、iOS 覆盖和新增图层，不能仅凭新导出包存在判定迁移成功。

### 交互性能策略（2026-09-22）

- 已撤回全状态页面缓存：状态变化时的额外序列化会增加开销，不再以重复静态请求的微基准作为实际切页提速证据。
- HTML 预览按项目和模型哈希复用模型，直接渲染服务端页面帧；模型不匹配重新获取。点击期间若已有刷新正在执行，完成后立即补发刷新，不丢弃点击、不重排行为事件。
- 运行记录保持同步原子写入，使用紧凑 JSON 减少每次动作的序列化耗时；不以延迟落盘换取速度。导出清单及用户文档仍保持可读排版。
- 当前单项目链路测量：模型复用响应由 684821 字节降至 57969 字节；记录序列化中位数由 59.4 ms 降至 11.6 ms。实际设备点击到画面呈现的端到端延迟需单独验收，不能用接口数据替代。

### 资源刷新修正

图片和字体使用内容哈希地址，只有哈希命名的资源响应允许私有长期缓存；资源内容改变即生成新地址。原生图片下载与解码结果使用 64 MB 成本上限的 LRU 缓存，按项目、资源、缩略图参数和解码尺寸区分。源码监听在遍历前剪除生成目录，旧源码目录内的 HTMLNativeStudio 导出产物不触发重新编译。实际切页与资源首载/再次访问需要分别验收，构建或网络头检查不能替代交互验证。

侧栏定期刷新使用 `/projects?summary=1`，只读取项目身份和页面名称；只有编辑器需要完整项目时才生成全部页面。禁止在每两秒的侧栏轮询中重新组合所有项目页面，避免占用交互锁。2026-09-22 本机验证：列表响应从约 1.77 MB 降为 3.6 KB，稳定 10 次请求中位数 11.2 ms；完整 iOS 页面响应 10 次中位数 31.1 ms、最大 45.7 ms。这些是接口测量，不能宣称为点击到屏幕显示耗时。已通过工作台镜像实际点击 HTML Start Design、iOS Preview、两端返回及再次进入页面，观察到正确切页和资源显示；镜像本身有延迟，尚未完成高速连续点击的逐帧延迟测量。
