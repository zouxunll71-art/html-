# 图层运行时动效 layer-presentation/1

`app.json` 页面可声明 `presentation: {when, rules, fallbacks}`。规则在源布局、iOS 外观覆盖、工作台新增图层合并之后执行，结果只用于当前渲染帧，不回写编辑数据。编辑模式跳过所有规则。规则选择器 `match` 支持稳定 `id`、catalog `asset`、`action`；多个条件必须同时满足。禁止项目专名硬编码进引擎。

`rules` 每项包含 `match`、可选表达式 `when`、`set` 和 `badge`。
- `set` 支持 offsetX/offsetY（相对于编辑后位置）、opacity、hidden、disabled、rotation、scale、layerOrder。隐藏/透明/禁用的动作不能触发。
- `badge` 为真实文本，支持 text 表达式、x/y/width/height（相对目标边界比例）、fontSize、color、shadow。文字跟随目标的父容器和自身旋转。
- `fallbacks` 是只在目标 ID 不存在时建立的运行时图片层，包含 id/asset/x/y/width/height，可选 rotation/layerOrder；用于纯 HTML 尚无工作台新增层时的同流程预览。不会重复创建已有图层，不出现在编辑状态。
- `runtime-only="true"` 的 HTML 节点只在运行帧出现，适用于舞台特效。
- `call` 动作字段为 action，调用已登记动作；每次状态更新总预算仍为256步，防止无限递归。
- `delay` 可指定 `scope:"page"`，离开、重进页面或切回编辑时取消旧轮次。已有未指定 scope 的延时语义不变。
- 新增表达式 `at(array,index)`、`mod(a,b)`。

使用既有 animate 实现位移、透明度变化。Web 和 UIKit 均遵守系统减少动态效果偏好。动画不替代静态编辑布局。

# 模型纹理分析 paint-analysis/1

`ui-model` 新增 `analysis-action`，`paint-options.command` 新增 `type:"analyze"`。与保存回调分离，分析不创建收藏、不写入纹理。回调 event.value 包含 version:1、model、work、seq、regions（12项coverage与saturation）。只有命令发起端执行，编辑模式不执行。

算法：以模型局部 XZ 中心划分12个角度扇区，按三角形真实面积加权，每个三角形4个重心UV采样。读取当前1024纹理，未使用的图集区域不参与。RGB最小通道小于245视为非白涂色；饱和度为(max-min)/max。coverage是非白涂色面积比例；saturation是非白区域的平均饱和度。空区域为0。旋转视角不参与评分。白色涂料和未涂白膜无法区分，不能用于评价白色作品的完成质量。

引擎只输出技术指标，评分规则由业务动作声明。本例采用 `round(coverage × (8 + 2 × saturation),1)`；不代表艺术水平、真人评分、社区投票或市场价格。相同作品应得到相同结果，不随机造分。模型或纹理无法读取必须显示错误，不产生成功分数。

## 导出时的绑定输入值
有 `bind` 的 ui-input / ui-textarea，其 iOS 覆盖中的 text 是运行时输入值，不属于静态本地化文案。导出在独立快照中去除此 text 覆盖，让绑定继续生效；位置、颜色、字体和其他外观覆盖原样保留。工作区记录不改动。静态文案、placeholder、选项与 action 覆盖仍须经过原有规范检查。
