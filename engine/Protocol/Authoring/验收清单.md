# 用户验收清单（本轮未执行）

使用 examples/NativeRules，再选择两个不同业务项目，确保没有页面名、资源名或包名特判。

1. 新建项目：393 基准；双语文件、原生导航、权限 key、前缀已生成；空白页可添加。
2. 文案：切换系统为英文/简体中文，导航、按钮、占位符、分段、参数文案对应；删除一个 key 或参数，编译错误明确；固定 HTML 中文或英文文本被拒绝。
3. 导航：在工作台左侧镜像与独立模拟器窗口分别点击原生标签切页；按钮 push 到详情隐藏标签栏；原生返回和侧滑返回两端一致；顶部栏不跟随滚动；不同项目切换不残留旧页面。
4. 链接：分别在两端点击隐私和协议，iOS 使用系统 Safari 容器；快速点击后立即切页不漏链接；点击工作台“关闭网页”后仍可继续操作；网页内容在真实模拟器窗口操作；独立 HTML 模式能查看链接。
5. 控件：输入、勾选、开关、分段、步进器、滑块的 state 绑定一致；空勾选框不自动附加协议文案；按钮 selected/disabled 及 styles 同步。
6. 加载：spinner 显隐，重复点击被禁用；delay 后清掉 loading 并导航；reset 取消待执行延时；关闭重开后未完成延时能继续；onEnter 不因滚动/重绘重复执行。
7. 弹窗：present/dismiss、关闭按钮、遮罩、双层弹窗和原生导航遮挡关系正确；输入时点空白能收键盘。
8. 资源复制：单图层/含子层；包含按钮、绑定输入、动态文案、重复列表；复制后原动作可触发，本地化和状态不被固定成快照；几何修改保留；改固定文案时导出提示回写 key。
9. 运行恢复：布局未保存时点击“运行 / 重启 iOS”；确认保存、构建、启动、安装、页面联动和画面 ACK。模拟构建失败时有阶段、日志和可关闭错误。不能删除现有 App 数据或抹掉模拟器。
10. 导出：不在当前页的页面/弹窗也存在；ExportInventory 对应全部资源；Swift 前缀一致、最低 iOS 15、Assets 与本地化齐全；无 hardcoded UI copy；关闭工作台后 App 可独立导航、输入、加载、弹窗、打开链接。
11. 导出目录：桌面 App名-htmlios；再次导出 App名-2-htmlios；旧导出未覆盖。
12. 性能：约 2000 张真实图片项目；冷载与热更新、当前页资源请求、拖动、翻页和缩略图滚动分别观察；资源压缩在副本进行，原图/原工程不修改。

语法检查、声明检查、构建成功、真实交互、视觉比对分别记录。不能用此前版本的测试结果充当此版本验收。

## UI 原图复刻验收（ui-replica/1）

- 新建/安装规范后的项目包含 `UI原图复刻规则.md`，AGENTS 与默认任务提示均引导阅读；不携带某个项目的业务和资源名。
- 页面、状态、入口/返回、资源、缺失项、字体替代及坐标换算清单齐全。
- 背景覆盖全屏和安全区，等比覆盖不拉伸；正文滚动、键盘变化不带走背景，四周无白缝。导航仍由系统管理。
- 只有复杂主页制作 QA 轮廓/锚点模板；普通页面直接测量。生产资源和正常访问不加载 QA 模板或整页参考图。
- 逐页保存同尺寸、同状态的原图/实际截图对照，主要差异修复后才标为视觉完成；不把静态通过、构建通过或相似度分数当作完整验收。
- 用户限制测试的通用页面只执行允许的视觉检查；清单明确区分未实现、未验证、可见差异。

## structured/1 新增人工验收项

以下由用户运行，未自动标记通过：
- 正常模板导入；实体文案、注释、自闭合 ui-* 和 tokens 保持原样。
- 错误字段、重复属性、不匹配标签、控件内嵌套图层均显示可定位错误，保留上次成功版本。

- 2000 资源项目测量同步耗时、内存与滚动表现；此次解析缓存改造未提供性能实测结论。
- 分享包在另一台电脑离线启动时能找到随包解析依赖；不依赖开发机 node_modules。
