# 本地日期、图片预览与实际安全区

这些能力服务于已有原型迁移，保留原生控件；不提供网络 AI、付款或上传服务。

## 日期和安全区

`clock.now` 是宿主注入的 Unix 毫秒时间；`clock.offsetMinutes` 与 JavaScript `getTimezoneOffset()` 一致，东八区为 -480。纯引擎不自行读系统时钟，隔离测试可注入固定值。

`dateFormat` 参数为 `[时间戳, 格式, 时区偏移分钟]`，支持 `day`（YYYY-MM-DD）、`time`（HH:mm）、`usDate`（M/D/YYYY）和 `iso`（UTC）。本地签到使用宿主偏移，UTC 签到传 0；续期以 `max(当前时间, 原到期时间)` 为基数。

`layout.width/height/top/bottom/contentHeight` 是当前模型和实际安全区的只读数据。源图属于全屏还是内容区应先记录；只扣一次安全区。不得按项目名称硬编码设备高度。不同宽高比下如采用整体等比适配，应在验收记录中同时保留原尺寸内容对照和原生全屏截图。独立背景资源可用 `placement="viewport-background"` 填满安全区，不得放置整页截图。

## 本地图片选择及预览

动作 `photoPreview` 必须声明 `path`、本地化 `title`、`message` 和 `close`。iOS 使用系统 PHPicker，只读取用户选择的单张图片，预览保持比例；网页使用文件选择器。联动时由 iOS 执行，避免两端重复打开。

选择结束后，声明的状态路径获得 `{status:"selected"}`、`{status:"cancelled"}` 或 `{status:"failed"}`。回调只接受一次；页面已切换或数据已重置时不回写旧页面。它只表示本地选择/预览结果，不能表示图片已发送、AI 已处理或已收费。图片不会上传，也不会自动登记为项目素材。

## 动态文字

`wrapText` 参数为 `[文本, 字体测量数据, 最大文字宽度]`，返回 `[换行后的文本, 实际最大行宽, 行数]`。测量数据包含 `widths`（字符宽度表）与正数 `fallback`，由原页面实际加载的字体测量，不能凭字符数猜宽度。保留显式换行、按词优先换行，过长单词逐字换行。

这不是所有文字系统的完美排版器：连字、复杂脚本、组合 emoji、未测量字符和两端栅格化仍需实际截图验收，不得据此宣称像素一致。可变字体的 `wght` 范围从字体文件读取并用于网页字体声明。

## 跨页本地延迟

`delay.scope` 默认 `page`；明确需要跨页完成的本地流程可使用 `project`，仅属于当前项目会话。换页不取消 project 延迟；reset 会使未完成回调失效。不同项目不共享状态。加载状态、失败、重复回调和退出后的恢复需要逐项测试。

## 聊天滚动定位

`scrollTo` 动作接受完整渲染节点路径 `node` 与非负坐标 `y`（`x` 可选）。布局按实际内容范围裁剪偏移。发送或接收后可请求到底部；不得在每次渲染强制滚动，用户仍可向上阅读。该动作只修改当前项目会话的滚动状态。
