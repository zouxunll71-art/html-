# 参考 UI 生成独立素材

修订：generated-assets/1（ui-replica/4）。适用于新生成的图片素材。现有项目不自动替换资源；用户当前明确指令优先。

## 生产边界与验收标准

只通过图像工具生成素材，不使用原始独立图片、不裁切/抠图、不复制 UI 参考图像素作为正式资源。完整参考 UI 必须作为真实图片传给工具，文字描述不能替代图片输入。参考原图可只读用于测量和 QA，不得进入正式页面背景或隐藏节点。使用当前可用图像工具/技能，不自行改用外部收费 API。

必须保留：主体身份和脸型、宏观轮廓、宽高比、姿态、视角、关键部位相对位置、主色、材质观感、光照方向，以及回填页面后的整体构图。人物手指与肢体正常，杯柄等孔洞正确，边缘无杂色，无 UI 背景残留。主体默认完全不透明；只有边缘过渡及本身半透明材质允许部分 Alpha。

允许不同：斑点的具体分布、细小纹理、单根发丝。不要求这些随机细节逐像素一致。此例外不能用于换脸、改姿态、改变主色或材质，也不放宽页面文字、字体、布局、图标语义、交互和安全区。

四项结论分开：资源整体视觉、页面几何/文字、交互、严格像素一致。完整差分仍保存；允许的微观差异不判成布局失败，也不冒称零差异。现有自动参数校准器仍保留严格零差异门槛，不自动认可感知相似，不因本规则修改 --apply 的保护条件。

## 执行步骤

1. **测量目标**：确定页面/状态、完整参考图及哈希、目标 ID、sourceWidth/Height、sourceBounds、轮廓/visibleBounds、面部/手/物体等关键点、旋转角度、主色、材质、遮挡和允许裁切边界。记录量测依据，不编造精确轮廓。单资源实验只审计相关目标。
2. **生成约束**：传入完整 UI；通过目标区域、标注或关键点说明对象。声明只输出目标、背景是否真实透明、主体应不透明、排除哪些 UI/道具；锁定身份、姿态与比例，允许细纹理差异。不得把“生成”执行为直接抠图。
3. **检查候选**：保留每轮原文件、提示、实际工具输入和输出路径。读取真实尺寸及 Alpha；区分请求尺寸、实际尺寸、交付尺寸。检查主体透明度及孔洞，不能把带 Alpha 通道当作主体正确不透明。背景照片无需强制透明。
4. **精确交付尺寸**：优先请求目标宽高比；生成工具不保证提示词尺寸。需要派生时，仅对生成结果做统一等比缩放和透明补边，记录比例及偏移，禁止拉伸。裁切不得超出已登记允许边界；意外裁到关键内容则重新生成。派生结果不冒称工具原生按目标尺寸生成。
5. **回填真实页面**：在隔离预览中按模板统一缩放/锚点放置候选，记录 object-fit、object-position 和裁切。使用实际 HTML 渲染截图，与同状态 UI 并排、叠加、差分检查；不得把整张 UI 作生产背景或合成参考图冒充实际页面。检查正常 UI 点击和图片加载。用户仅要候选预览时可先交候选，注明页面回放未验证。
6. **定向修正**：列出主要偏差，优先身份/姿态 → 轮廓比例/关键点 → 主色/材质 → Alpha/边缘。每轮将原 UI 与当前候选作为参考，只修最主要一项，并重申已经正确的约束。保留所有轮次，变差就回退；默认最多三轮，仍不满足则报告具体失败，不无限重试或自行降低标准。
7. **正式接入**：资源视觉、页面回放与交互均有证据后才接入 catalog。单张素材生成成功不等于整页验收通过。同源重复素材复用确认版本，不按页面重新生成造成漂移。未授权不替换业务项目或外层 iOS 工程资源。

被遮挡或裁掉的部分只能生成推断，记录范围；限制补全以免多生成半身、道具或肢体。人物实验已观察到模型扩展下半身、请求尺寸与实际尺寸不同，以及主体 Alpha 约 98%～99% 的情况，均须实测，不当成固定模型规律。

## 提示模板

> 使用随附的完整 UI 图片作为视觉参考，重新生成【区域/资源 ID】的【主体】独立素材，不进行原像素提取。原图尺寸【W×H】，目标范围【x,y,w,h】，关键点【坐标及单位】。保持【身份/脸型、姿态、角度、轮廓比例、主色、材质】，不独立缩放头部或道具。允许斑点分布、细纹理和单根发丝变化。排除【无关 UI、背景、道具】。请求【像素尺寸/宽高比】，背景【真实透明/场景】，主体【不透明/指定半透明材质】。允许裁切【边界】，不可见部分【不扩展/有限推断范围】。只输出一个素材，不输出对比图。

## 可执行的 PNG 检查

安装校准依赖后运行（工具只读图片，不调用模型、不修改图片）：

```sh
node .studio/authoring/calibration/inspect-asset.mjs candidate.png --width 1024 --height 1408
```

输出 actualWidth/Height、尺寸匹配、透明/半透明/不透明像素统计、Alpha 分布、visibleBounds 和技术警告。可添加 `--opaque-region x,y,width,height` 指定预期完全不透明的主体内部矩形，检测任何低于 255 的 Alpha。它不自动判断人物、材质、视觉相似或通过；内部区域需要人工测量，边缘不要放进该矩形。缺少完全透明像素不一定错误，背景照片可保持不透明。

将 JSON 保存至 qa/assets/<id>/inspection.json；图片/脚本参数错误会失败退出，技术警告保留为待检查事项。只支持 PNG；其他格式先按工具规范生成或另行检查，不伪称检测成功。

## 记录格式

在 qa/assets/<id>/record.json 记录：reference、referenceSHA256、sourceSize、sourceBounds、keypoints、requiredInvariants、allowedVariations、occludedRegions、requestedSize、actualSize、deliverySize、transforms、prompt、candidatePath、candidateSHA256、iteration、inspectionPath、pageScreenshot、comparisonPaths、interactionEvidence、visualStatus、pixelExactStatus、remainingIssues。未完成字段写 null/未验证，禁止编造通过。

本版提供的是 Codex 可执行的生成规范、提示模板和 PNG 检查工具；未新增工作台生成按钮、后台自动生图服务或自动视觉审批算法。
