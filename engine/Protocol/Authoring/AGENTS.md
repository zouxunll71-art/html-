本项目由 HTML Native Studio 的 html-native/1 模板创建，iOS 工程规则修订为 native-rules/2。

开始前读取 `.studio/authoring/HTML编写规范.md`、`.studio/authoring/iOS工程规则映射.md`、`.studio/authoring/capabilities.json` 、`.studio/authoring/schemas.json` 和 `app.json`。参考当前示例 `.studio/authoring/examples/NativeRules`；旧示例用于旧协议对照，不能作为新工程入口。

有参考图时按《参考图布局规则.md》统一映射画布：新工作台项目保留协议的 393 逻辑宽度，高度按原图比例计算；无参考图时才使用 393×852 初始模板。既有项目保留其 viewport，不为套模板重排。手机外壳、安全区和系统导航由工作台管理。不要在 HTML 画业务导航栏、状态栏、灵动岛或 Home 指示条。

有 UI 原图的任务必须完整读取 `.studio/authoring/UI原图复刻规则.md`（ui-replica/4）。首次复刻严格执行本次范围内的审计、所有页面/状态坐标模板与校准模式、独立资源接入、按模板布局、抽离模板、截图差分及交互验收、交付。首次审计完成前不得写页面；普通页不豁免模板。后续局部修改按复刻规则“首次复刻与增量修改”复用有效证据，只更新受影响范围。图片素材只生成，遵守《生成素材规则.md》整体视觉验收；允许细纹理、斑点和发丝不同。字体、布局、文字和交互仍严格核对；缺失和未验证项如实记录。纯 HTML 任务仅交付 HTML/CSS/JavaScript，不修改或构建原生工程；工作台项目继续遵守 ui-* 协议和外层工程保护边界。

所有页面与弹窗显式登记；图片/字体完整登记 assets/catalog.json；稳定图层 ID 不随内容变化。UI 文案使用 text-key、placeholder-key、option-keys 或 t 表达式；en 和 zh-Hans 必须具有相同的 key 和参数。真实用户内容可从数据绑定读取，不能借此藏静态 UI 文案。SF 图标用 ui-icon；金币图标统一使用 ios.currencySymbol 的 UIImage，不能用文字符号。

每个按钮登记 action，每个可编辑控件登记 bind 或 action。页面进入动作登记 onEnter，定时步骤使用 delay；加载使用 ui-spinner + when，禁用和选中状态显式绑定。隐私、协议链接登记 links，通过 openURL 打开 iOS 系统 SFSafariViewController。

HTML 是行为与资源来源，iOS 覆盖用于独立调整外观。不能改系统安装目录、Workspace、运行状态或 overrides；不能用整页 PNG、WebView 或虚假的成功反馈充当原生实现。遇到协议未支持的能力，明确报告并补充协议后再使用，不静默删减。

遵守用户的构建/测试安排：用户说明自己测试时，不启动模拟器、不执行构建或运行测试。交付时明确区分语法/声明静态检查、实际构建和两端交互测试；未做的不能标为通过。默认授权范围内可运行 `python3 .studio/authoring/validate.py`，再按验收清单测试；明确的用户限制优先。

## 工作台后台镜像（供 Codex 使用）
仅在任务需要检查桌面界面且使用者正在运行 HTML Native Studio 时，可通过浏览器工具在隐藏标签页打开 `http://127.0.0.1:18777/mirror`，优先查看其当前桌面画面，不向使用者弹出额外窗口。应用不会主动创建 Codex 标签页。镜像支持点击、滚动、文字写入，操作与桌面端同步，作用于同一项目；操作前确认项目和草稿，严格遵循使用者当前授权。复杂拖拽和系统文件选择器仍用桌面操作工具。镜像有秒级延迟，断开时可能保留最后画面，必须检查同步状态。只有连接镜像时才采集画面；这不是远程公开服务，也不分享其他人的账号或数据。

新建项目目录约定：HTMLNativeStudio/HTML/ 是 HTML 源码和规范的根目录，HTMLNativeStudio/iOS/ 存放导出的 Xcode 工程。保持已有项目路径不变，不擅自迁移旧项目；勿把生成的 iOS 工程写进 HTML 源码目录。

## 开发与验证入口（browser-first/1）

默认在 Codex 内部浏览器的 HTML 手机中完成工作台页面复刻，保存同一源码后自动更新；不要求先打开桌面工作台、构建原生应用或启动模拟器。浏览器阶段仍是 html-native/1 项目，使用 ui-*、app.json、资源 catalog、声明式动作和本地化；“先做 HTML”“只开浏览器”不表示改用无法同步的普通网页。仅用户明确要求独立普通网页时采用普通 HTML/CSS/JavaScript，并说明它不自动转换为工作台项目。

- 工作台页面任务：静态声明检查 → 项目绑定的 `/browser` 实际渲染 → 同状态截图对比与受影响交互验收。预览仅显示手机；没有顶部页面菜单，导航通过页面自身交互。测试指定状态时使用受支持的项目会话接口或隔离 QA 工具，不虚构 `?qa=` 模式、不永久改入口/跳转来留住截图。
- 原生能力或 iOS 差异任务：按授权开启对应项目工作台，再做实际 iOS 验证；HTML 通过不能代替 iOS 通过。共享渲染器或控件变更才扩大到受影响的双端与多结构联调样例。
- 桌面工作台界面任务：必要时构建并加载客户端，使用 `/mirror` 检查真实桌面状态。`/mirror` 是桌面截图入口，不能代替 `/browser` 的 HTML 清晰度和像素验收。
- 外层成品工程与导出继续遵守显式授权边界。遵守用户关于构建、运行和测试的限制，未做的检查写为未验证。浏览器无需构建原生应用不等于无需真实截图和交互检查。

启动方式：维护仓库中可执行 `npm run preview:html -- --source '/绝对项目路径'`。业务目录不一定有该 npm 命令；读取 `.studio/authoring/system.json` 的 `systemRoot`，执行 `python3 '<systemRoot>/scripts/browser_preview.py' --source '/绝对源码路径'`，使用实际返回的项目 URL。不要把安装路径写死到业务文件，不打印或复制服务管理令牌。

浏览器与桌面共用真实源码和编译记录，不另建发布副本。打开桌面后选择该项目读取最新 HTML；保留用户 iOS 覆盖及新增图层，不以“同步”为由清空。浏览器和桌面 HTML 共用项目会话，测试点击可能改变同项目页面状态；并行验收使用联调样例，避免干扰用户操作。

清晰度验收使用实际 DOM 和原资源，等待字体与图片加载完成，记录 CSS 视口、DPR、截图像素及显示缩放。精确截图使手机内容处于 1 倍显示比例或使用经验证的无缩放隔离渲染；不把缩小后的整窗截图放大当原尺寸证据。手机壳不进入 UI 差分，原图系统区域和内容区域的边界须一致。不要用低清缩略图、截图流、双重缩放替代 HTML；低分辨率源素材需单独报告，不能靠 CSS 锐化冒称恢复细节。

## 工作区边界与外层 iOS 工程保护

本项目的 AI 工作区仅限 `HTMLNativeStudio/`；页面、资源和业务源码位于 `HTMLNativeStudio/HTML/`，导出包、迁移清单及备份位于 `HTMLNativeStudio/iOS/`。开始任务前必须读取本规则和 HTML 目录内的 AGENTS.md。

- 外层 `.xcodeproj`、`.xcworkspace`、应用源码目录及其中的 Swift、资源、Info.plist、entitlements、Storyboard、签名、Bundle ID、构建设置均为受保护内容。可以只读检查，不得修改、删除、移动或覆盖。
- 日常开发、修复、预览、同步和验证只在 HTMLNativeStudio 内进行。不得以修复编译、同步页面、完成任务或“拥有完全访问权限”为由扩大写入范围；不得通过脚本、符号链接或命令间接修改外层。
- 默认构建授权仅适用于工作区；构建产物、DerivedData、日志等也应留在工作区，不得自动构建或修复外层成品工程。
- 只有用户在工作台明确点击“导出”，才由系统导出流程迁移代码和资源到外层。AI 不得自行调用导出接口、运行迁移脚本或模拟点击导出来绕过边界。用户另有明确指示时，仅按该次具体授权执行。
- 导出后工作区仍可编辑；外层成品不随工作区编辑自动变化。用户再次点击导出，才更新系统上次生成的代码和资源；工程配置始终保留，不得擅自修改。
- 发现需求必须改外层时，先说明具体原因与文件，等待用户明确指示；不能先改后告知。本规则优先于本项目中笼统的自动构建、自动修复和完成任务说明。

## 编辑与预览约定

修改前阅读 HTML编写规范.md 的“工作台编辑与预览行为”。启动页暂停、选区关联和默认转场属于工作台能力，不能靠修改某个业务项目的跳转、固定偏移或删除遮罩替代修复。HTML 与 iOS 关联选中不代表关联编辑；稳定图层 ID 不按图片名或显示文字推断。

项目源码任务发现共享工作台异常时，报告对应代码层与证据，不自行越界修改安装目录。只有用户授权维护系统时才进入客户端/共享引擎的维护流程。构建、坐标计算、实际交互和视觉验收分别记录，未完成项明确保留。

指定原图内资源单独生成时，遵循 UI原图复刻规则.md 的“带 UI 原图指定资源单独生成”：把实际 UI 图片传入图像工具，明确目标区域，逐资源输出并核对；仅文字提示和单张候选不能代替真实页面回填验收；随机细节按生成素材规则处理。

兼容尚未重新安装规范的项目：若项目内缺少校准脚本，读取 `.studio/authoring/system.json` 的 systemRoot，在该目录的 Protocol/Calibration 使用已安装工具和 README.md；不覆盖旧项目定制规范，不因此改动业务源码。

## Codex 内部浏览器 HTML 手机

用同一份工作台结构化 HTML 源码在 Codex 浏览器中复刻页面，无需打开桌面工作台或启动模拟器：

```sh
# 在系统维护仓库中运行；业务目录启动方式见上文
npm run preview:html -- --source '/绝对路径/你的项目'
```

命令返回项目固定的 `url`，在 Codex 内部浏览器打开。引擎内也可直接执行 `python3 scripts/browser_preview.py --source '/项目路径'`。支持源目录本身或外层包含 `HTMLNativeStudio/HTML` 的工程目录。普通 HTML 不会自动转换或被覆盖；页面仍遵循 html-native/1 协议。

- 浏览器复用工作台的编译器、HTML 渲染器、字体和独立资源。保存源码自动更新。浏览器只显示手机预览，不显示顶部项目名、页面菜单或同步提示；通过页面自身按钮进行操作。
- 项目按真实源路径登记到同一个 Workspace；之后打开桌面工作台、选择该项目，HTML 手机读取同一份最新模型，不需要导入副本。iOS 外观覆盖与新增图层保留，HTML 与 iOS 外观仍可能存在用户自己的差异。
- 浏览器链接固定绑定项目，多个标签可预览不同项目；不会切换桌面当前项目，也不会分配、启动或关闭模拟器。
- 浏览器使用项目 HTML 会话，按钮操作不转发到 iOS 会话；工作台中的 HTML 与此页共用 HTML 会话。网页渲染使用运行模式，不修改桌面选取/运行开关。
- 只有源码编译错误时显示临时提示并保留最后一次成功页面，不能将旧画面视为已更新。停止访问后约 30 秒不再维持该项目的浏览器源码监听；已开启的桌面工作台监听不受影响。
- 浏览器地址包含只允许该项目 HTML 预览操作的本机凭据，不允许操作其他项目、原生设备、iOS 编辑或导出。不要把地址发布到公网。

这不是 `/mirror` 桌面截图入口，也不使用另写的一套 HTML 模板。原生 SF Symbols 由本机图标辅助程序输出；浏览器本身的文字栅格与 WKWebView 可能存在差异，不能据此宣称逐像素一致。


### 浏览器清晰度

浏览器入口按页面逻辑尺寸显示，窗口足够时 1 个设计坐标单位对应 1 CSS 像素，消除工作台 402 宽归一化在浏览器中的第二次缩放。Retina 清晰度由浏览器 devicePixelRatio 渲染；窗口不足时只进行一次等比缩小。图片端点返回原资源字节，不使用模拟器视频帧、JPEG 转码、缩略图或低清预览替代。像素画沿用项目 image-rendering 设置，不把所有图片强制设为 pixelated。字体与真实文本继续由共享渲染器输出。
