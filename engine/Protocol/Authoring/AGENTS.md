本项目由 HTML Native Studio 的 html-native/1 模板创建，iOS 工程规则修订为 native-rules/2。

开始前读取 `.studio/authoring/HTML编写规范.md`、`.studio/authoring/iOS工程规则映射.md`、`.studio/authoring/capabilities.json` 、`.studio/authoring/schemas.json` 和 `app.json`。参考当前示例 `.studio/authoring/examples/NativeRules`；旧示例用于旧协议对照，不能作为新工程入口。

新项目以 393 pt 宽度为基准，模板高度 852；位置、字号、间距按宽度统一缩放。手机外壳、安全区和系统导航由工作台管理。不要在 HTML 画业务导航栏、状态栏、灵动岛或 Home 指示条。

有 UI 原图的任务必须完整读取 `.studio/authoring/UI原图复刻规则.md`（ui-replica/4）。严格执行审计、所有页面/状态坐标模板与校准模式、独立资源接入、按模板布局、抽离模板、截图差分及交互验收、交付。UI_AUDIT.md 完成前不得写页面；普通页不豁免模板。图片素材只生成，遵守《生成素材规则.md》整体视觉验收；允许细纹理、斑点和发丝不同。字体、布局、文字和交互仍严格核对；缺失和未验证项如实记录。纯 HTML 任务仅交付 HTML/CSS/JavaScript，不修改或构建原生工程；工作台项目继续遵守 ui-* 协议和外层工程保护边界。

所有页面与弹窗显式登记；图片/字体完整登记 assets/catalog.json；稳定图层 ID 不随内容变化。UI 文案使用 text-key、placeholder-key、option-keys 或 t 表达式；en 和 zh-Hans 必须具有相同的 key 和参数。真实用户内容可从数据绑定读取，不能借此藏静态 UI 文案。SF 图标用 ui-icon；金币图标统一使用 ios.currencySymbol 的 UIImage，不能用文字符号。

每个按钮登记 action，每个可编辑控件登记 bind 或 action。页面进入动作登记 onEnter，定时步骤使用 delay；加载使用 ui-spinner + when，禁用和选中状态显式绑定。隐私、协议链接登记 links，通过 openURL 打开 iOS 系统 SFSafariViewController。

HTML 是行为与资源来源，iOS 覆盖用于独立调整外观。不能改系统安装目录、Workspace、运行状态或 overrides；不能用整页 PNG、WebView 或虚假的成功反馈充当原生实现。遇到协议未支持的能力，明确报告并补充协议后再使用，不静默删减。

遵守用户的构建/测试安排：用户说明自己测试时，不启动模拟器、不执行构建或运行测试。交付时明确区分语法/声明静态检查、实际构建和两端交互测试；未做的不能标为通过。默认授权范围内可运行 `python3 .studio/authoring/validate.py`，再按验收清单测试；明确的用户限制优先。

## 工作台后台镜像（供 Codex 使用）
如果使用者正在运行 HTML Native Studio，可通过浏览器工具在隐藏标签页打开 `http://127.0.0.1:18777/mirror`，优先查看其当前桌面画面，不向使用者弹出额外窗口。应用不会主动创建 Codex 标签页。镜像支持点击、滚动、文字写入，操作与桌面端同步，作用于同一项目；操作前确认项目和草稿，严格遵循使用者当前授权。复杂拖拽和系统文件选择器仍用桌面操作工具。镜像有秒级延迟，断开时可能保留最后画面，必须检查同步状态。只有连接镜像时才采集画面；这不是远程公开服务，也不分享其他人的账号或数据。

新建项目目录约定：HTMLNativeStudio/HTML/ 是 HTML 源码和规范的根目录，HTMLNativeStudio/iOS/ 存放导出的 Xcode 工程。保持已有项目路径不变，不擅自迁移旧项目；勿把生成的 iOS 工程写进 HTML 源码目录。

## 默认构建并验证修复效果

使用者已授权：完成本次请求范围内的代码修改后，默认自行执行必要的本地校验、构建、安装或加载更新，并通过隐藏的浏览器镜像检查实际修复效果，无需为这些步骤逐次请求确认。使用者当前明确要求不构建、暂不运行或自己测试时，以当前要求为准。

验证顺序：先确认修改的项目和运行版本，完成构建并让运行实例加载新版本，再用浏览器工具在后台打开 `http://127.0.0.1:18777/mirror`，进入本次修改的具体页面或状态，检查显示与交互；发现问题就继续修复并复测。工作台客户端使用 `npm run build:mac`，业务项目使用自身规定的校验和构建入口，不套用客户端命令。

重载或重启前保留用户未发送的草稿和附件，不中断正在运行的任务。镜像不支持的操作可使用原生桌面工具。构建成功不等于效果验证通过；交付时区分构建结果、实际界面验证和未验证项，不以源码检查或旧画面替代运行验证。默认授权限于当前任务的本地修改与验证，不因此自动发送模型消息或扩展任务范围。

## 工作区边界与外层 iOS 工程保护

本项目的 AI 工作区仅限 `HTMLNativeStudio/`；页面、资源和业务源码位于 `HTMLNativeStudio/HTML/`，导出包、迁移清单及备份位于 `HTMLNativeStudio/iOS/`。开始任务前必须读取本规则和 HTML 目录内的 AGENTS.md。

- 外层 `.xcodeproj`、`.xcworkspace`、应用源码目录及其中的 Swift、资源、Info.plist、entitlements、Storyboard、签名、Bundle ID、构建设置均为受保护内容。可以只读检查，不得修改、删除、移动或覆盖。
- 日常开发、修复、预览、同步和验证只在 HTMLNativeStudio 内进行。不得以修复编译、同步页面、完成任务或“拥有完全访问权限”为由扩大写入范围；不得通过脚本、符号链接或命令间接修改外层。
- 默认构建授权仅适用于工作区；构建产物、DerivedData、日志等也应留在工作区，不得自动构建或修复外层成品工程。
- 只有用户在工作台明确点击“导出”，才由系统导出流程迁移代码和资源到外层。AI 不得自行调用导出接口、运行迁移脚本或模拟点击导出来绕过边界。用户另有明确指示时，仅按该次具体授权执行。
- 导出后工作区仍可编辑；外层成品不随工作区编辑自动变化。用户再次点击导出，才更新系统上次生成的代码和资源；工程配置始终保留，不得擅自修改。
- 发现需求必须改外层时，先说明具体原因与文件，等待用户明确指示；不能先改后告知。本规则优先于本项目中笼统的自动构建、自动修复和完成任务说明。

## 编辑与预览约定

修改前阅读 HTML编写规范.md 的“工作台编辑与预览行为”。启动页暂停、选区关联和默认转场属于工作台能力，不能靠修改某个业务项目的跳转、固定偏移或删除遮罩替代修复。HTML 与 iOS 关联选中不代表关联编辑；稳定图层 ID 不按图片名或显示文字推断。

项目源码任务发现共享工作台异常时，报告对应代码层与证据，不自行越界修改安装目录。只有用户授权维护系统时才进入客户端/共享引擎的维护流程。构建、坐标计算、实际交互和视觉验收分别记录，未完成项明确保留。

指定原图内资源单独生成时，遵循 UI原图复刻规则.md 的“带 UI 原图指定资源单独生成”：把实际 UI 图片传入图像工具，明确目标区域，逐资源输出并核对；仅文字提示和单张候选不能代替真实页面回填验收；随机细节按生成素材规则处理。

## 像素级复刻升级（ui-replica/4）

按 UI原图复刻规则.md 的执行门槛：锁定参考原图及哈希，读取生成文件真实像素并区分 pt/CSS px/DPR；资源和字体先独立验收；同一参数源驱动模板与页面；连续截图稳定后做分区域及整页差分；按几何、裁切、轮廓、文字、颜色顺序校准，回归即回退。纯 HTML 任务只验证 HTML；已授权双端任务分别对照同一原图，外层工程仍受显式导出边界保护。自动校准能力以 自动参数校准.md 的实现范围为准，未支持能力明确标记，不将规范当功能上线或验收证据。交付补充 qa/reference-manifest.json、qa/capture-environment.json、实际尺寸及校准记录。

自动参数校准工具已随规范提供于 `.studio/authoring/calibration/`。有可运行 HTML、锁定原图和测量参数时先读 `自动参数校准.md` 并执行截图校准；此工具的严格像素判定仍要求零差异，生成素材的整体视觉按《生成素材规则.md》另外验收，使用 --apply 后必须验证持久化源码。ui-* 原文件须先通过 export-preview.py 使用真实渲染器生成隔离预览；尚不支持校准 iOS，不得用候选结果代替最终输出。

兼容尚未重新安装规范的项目：若项目内缺少校准脚本，读取 `.studio/authoring/system.json` 的 systemRoot，在该目录的 Protocol/Calibration 使用已安装工具和 README.md；不覆盖旧项目定制规范，不因此改动业务源码。
