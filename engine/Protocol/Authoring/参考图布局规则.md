# 参考图驱动布局（reference-layout/1）

本规则优化结构化 HTML 的复刻过程，保留现有 UIKit 原生控件、原生导航、动作绑定和导出方式，不把普通网页替换成另一套运行系统。

## 原图决定构图，协议负责表达

393 是新 iOS 工程目前的协议设计宽度，不是让作者把每张原图重新设计成 393×852。852 仅用于无参考图时的初始模板，不是复刻限制。先读取原图实际宽高，再统一按 s = viewportWidth / sourceWidth 换算，参考高度为 sourceHeight × s。不能把横纵坐标分别按 393 和 852 缩放。不要通过修改既有项目 viewport 重新排列用户布局；工具输出仅为候选。

必须说明原图是全屏截图还是内容区截图。模板输入 source-screen 坐标必须来自完整应用画布；若资料只有内容区，先记录它相对完整画布的偏移，不猜状态栏高度。iOS pt、截图 px、HTML CSS px、DPR 分开记录。实际设备更高/更矮属于另一项适配，不把参考图本身拉伸去匹配设备。

原生导航与控件继续使用系统既有实现。使用本次预览实测的 contentInsets，而不是从参考图猜测或固定写死；也不为贴合图片擅自隐藏原生栏位。屏幕坐标转根内容坐标只扣一次顶部 inset。子图层再减去父图层屏幕原点，不重复扣安全区。viewport-background 使用完整画布坐标。

## 可执行坐标换算

项目安装规范后运行：

```sh
node .studio/authoring/calibration/map-reference.mjs qa/home-layout-input.json > qa/home-layout-candidate.json
```

示例输入（尺寸仅为示例；请实测）：

```json
{
  "coordinateSpace": "source-screen",
  "sourceWidth": 1206,
  "sourceHeight": 2622,
  "viewportWidth": 393,
  "contentInsets": {"top":103,"bottom":34},
  "elements": [
    {"id":"panel","x":60,"y":360,"width":1086,"height":900},
    {"id":"title","parentId":"panel","x":90,"y":390,"width":600,"height":120,"fontSize":48}
  ]
}
```

输出统一缩放后的屏幕边界及父容器内 absolute 布局候选，字号、行高、字距、圆角、描边使用相同缩放。不要将候选的根元素直接设为 ui-page；根元素作为 ui-page 的子层，ui-page 本身保留内容区布局。可选 viewportHeight 只用于校验宽高比，比例不同会报错，不偷偷进行二次缩放。

所有元素 x/y 是同一张原图上的屏幕坐标，而非已经相对父级的数值。它们是布局边界，不是旋转后外接矩形。父级有旋转、缩放或滚动时必须先做逆矩阵测量；本工具明确报错，不生成看似正确的错误坐标。复杂文本的 OCR 字形框不等于控件文字框，需核对基线、行高与字体后才能采用。工具不修改图像、项目或原生工程，也不自动验收视觉效果。

## 避免协议限制引起擅自简化

- 可测量的复杂构图允许使用 absolute 定位、stack 叠放和独立素材；不要为了方便套 column/row 导致重排。重复列表和需要自适应的区域继续使用适当布局，不强制全页绝对定位。
- 文字不要依赖 auto 高度或默认 44 高度。登记实际字体、字号、行高、字距、行数及文字框；只调字体或只调外框不能冒称还原。
- 不支持的 CSS 必须定位到具体节点和视觉目的，写入能力缺口；优先用已有协议的等价结构表达。无法等价表达时报告并修复系统能力，不删除阴影、简化裁切、换配色或改构图来通过校验。
- 保留父级关系和裁切声明；置顶不能解除裁切，排序不代表改父级。图片容器与图片实际可见轮廓分开核对；fit/fill 必须按渲染含义选择，不能拉伸素材。
- 本地化、稳定 ID、资源 catalog、动作、原生控件和外层工程边界仍有效，不是视觉简化的理由。

## 验证

模板坐标 → 候选 → 实际 HTML 渲染截图 → 原图并排/叠加/差分 → 真实点击与输入。记录几何误差、素材差异和渲染差异，三者不能互相掩盖。允许生成素材的微观纹理差异，不放宽布局与文字。新增工具只能证明坐标转换，不证明每页视觉已通过；现有业务页面不自动迁移。

浏览器阶段使用同一份 viewport 和坐标，不为浏览器宽高另存一套布局。窗口显示缩放属于预览宿主，不写回元素坐标。精确截图在 1 倍内容显示下按实际 DPR 采集；小窗口只用于查看，不将其放大截图当作原分辨率验收。具体入口按 AGENTS.md 的 browser-first/1，局部变更范围按 UI原图复刻规则.md。
