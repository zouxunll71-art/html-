# 通用 3D 模型与彩绘（model-paint/2）

`ui-model` 使用 `model-asset` 引用 catalog 的 `kind:model` GLB；原 profile 回转体能力保持不变。Web 使用 Three.js，iOS 使用原生 SceneKit 与 Metal，不使用 WebView 或封面图冒充运行实现。

支持：GLB 2 内嵌静态三角形网格、FLOAT POSITION / NORMAL / TEXCOORD_0、8/16/32 位索引、节点矩阵和 TRS。白膜彩绘使用共享 1024×1024 线性 RGB UV 纹理。暂不支持骨骼、动画、变形、Draco/Meshopt、稀疏或归一化顶点属性；这些输入在原生加载时明确报错。此版本不是完整 glTF 场景播放器。

`paint-options` 字段：color 为 HEX，size 为笔刷半径，opacity 为浓度，mode 为 0 涂色 / 1 旋转 / 2 擦除，work 为已保存作品 ID，command 为 `{type,seq}`，type 可用 undo/redo/clear/save。显式保存只有写入成功后才回传 bind/action；失败保留画布并显示错误。两端联动时命令只在操作发起端执行，防止重复保存。

图层位置、尺寸、rotation、scale 仍由工作台负责；运行时拖动模型是内部视角/彩绘交互。iOS 双指捏合缩放，Web 滚轮缩放。运行模式与编辑模式分开，编辑时不吃掉图层工具手势。

工作台作品通过既有认证通道按项目隔离保存；闲置画布约每 2 秒读取纹理修订，活动笔画期间暂停同步。视角及撤销栈属于当前画布，不在两端之间同步。不支持多人同时涂同一作品（最后完成的整张纹理保存生效）。

iOS 导出包含 GLB 和原生代码，离线作品保存在 App Application Support。工作台已有作品不会自动复制进导出 App。导出源码能构建不等于真机或 App Store 验收完成。

验收证据及限制见工作台 `artifacts/model-native-qa.md`。
