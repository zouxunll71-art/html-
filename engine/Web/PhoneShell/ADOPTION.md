# 外壳来源与接入

原始 index.html、style.css、README.md 原样复制自用户指定的 web手机目录。运行入口 Web/index.html 使用同一套外壳样式。

- 内容 402 × 874；外框 434 × 906；灵动岛 122 × 34，top 12。
- 原 CSS 的 border-box + border 2 + padding 16 会让内容向右下偏 2px；运行版 padding 调为 14，使左右上下均为 16px。原始副本保留不变。
- 工作台宿主使用 456 × 910 坐标；外壳原点 11,2；内容原点 27,18，与左侧模拟器内容对齐。
- 整体等比缩放；业务页面只进入 #screen（位于 #app-viewport 内）。
- 工作台隐藏外围的大投影，避免两台手机之间遮挡。
- 外壳不参与业务节点提取或导出。
