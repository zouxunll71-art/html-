# iPhone 17 Pro Web 手机模板

这是 HTML 流水线所有新项目的第一版手机外壳。

- 内容视口：`402 × 874 CSS px`
- 对应设备：iPhone 17 Pro
- 官方物理分辨率：`1206 × 2622 px`
- 像素倍率：`3×`
- 初始内容：纯黑屏
- 手机位置：浏览器中央

## 使用规则

1. 新 HTML 项目的第一步是把 `<local-project-path>` 的手机工作文件复制为新的项目目录。
2. 只在复制后的项目中增加页面、资源、业务代码和数据。
3. 本模板目录保持为干净的第一版手机，不直接写入任何具体 App 内容。
4. App 页面只能放进 `#app-viewport`，不得改变其 `402 × 874` 内部设计坐标系。
5. 浏览器空间不足时只允许等比缩放整个手机，不得重新排布或压缩内部页面比例。
6. 复制时排除 `.git/`、`.DS_Store` 和 `.openai/`；它们是模板自身的版本或托管身份，不属于手机代码，新项目不得继承。
